# Lichen Zhao · 赵立晨

**Co-founder & CTO at [Lagrange](https://lagrangex.com)**<br>
Building infrastructure for agents that operate in the physical world.

My work has moved from competitive programming and 3D vision-language research, through large-scale multimodal pre-training and production edge-cloud agents, to **Physical Agent Infra** today.
